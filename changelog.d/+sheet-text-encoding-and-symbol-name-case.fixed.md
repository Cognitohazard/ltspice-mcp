`edit_schematic` reads an 8-bit sheet the way `inspect` does, byte for byte as Windows-1252, instead of refusing a sheet that holds a byte Windows-1252 leaves undefined or reading it in another code page; it writes the sheet back with the line ends it had, so every line an edit did not change keeps its bytes, and its reply says when a sheet's 8-bit text names no code page. A symbol or block sheet named in another letter case than its file is found on every platform, as on Windows; where two files differ only in case and neither is spelled as the sheet spells it, the reply names both, and `inspect` says when a part's symbol was not found.
