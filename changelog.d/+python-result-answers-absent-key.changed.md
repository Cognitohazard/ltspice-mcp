A result of the Python API now answers a field it left out with the value the reply left out: `[]` for a list, `{}` for an object, `False` for a flag and `None` otherwise, so `row["assignments"]` is `{}` for a run with no variation instead of raising `KeyError`. Nested objects, rows, raw pages and an `ApiCallError`'s `payload` answer the same way. A key the operation never declares, and a field the tool always keeps (such as `export.diff_vs_prior`), still raise; `in` still tells whether the reply carried a field, and the result's `repr` and `json.dumps` are unchanged.
