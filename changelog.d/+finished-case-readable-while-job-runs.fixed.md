A finished case of a job is now read while another case of the same job still runs. `inspect(kind="results")`, `plot_waveform`, `analyze_results`, `jobs(action="place_beside_sheet")` and the Python API's `load_raw`, `measurements` and `device_op_points` refuse only a case whose own run has not finished, with the new code `run_not_finished`, naming the case, what its simulator has written so far, and the wait. Before, every case of a job was refused until all of its runs had ended.
