The `summary` recipe no longer calls each requested `.meas` of a QSPICE or Xyce run, or of a run whose log was not read, "missing", and no longer reports measurement values the server does not read. It says once, in a `measurements_not_read` observation, the reason the run row gives in `measurements_coverage`. The `measurements` recipe, `inspect`'s results page of measurements and the Python API's `measurements` refuse such a run with that same reason, whether the run is named by job or its raw by path.
