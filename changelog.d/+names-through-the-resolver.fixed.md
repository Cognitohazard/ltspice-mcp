The `.save` and `.meas` coverage check now asks how the run's simulator stores a name, so it no longer refuses a node that is saved under the simulator's own spelling, and no longer passes a `.save` the simulator ignores. A device inside a block has one name whichever LTspice build wrote the table, names are compared with one case rule that folds ASCII letters only, and a node such as `v(Rinoise)` is no longer taken for input-referred noise.
