A `.save` or `.meas` in an LTspice deck that names a node inside a subcircuit instance with dots (`V(xamp.mid)`), as ngspice spells it, is now reported: LTspice 26 and XVII store and measure nothing for it, so the `.save` entry is a warning and the `.meas` is refused, with the build's own spelling (`V(xamp:mid)` or `V(amp:mid)`). Before, the checks said the reading was not established and let the run go ahead to a failed measurement.
