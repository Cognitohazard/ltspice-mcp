Each run row of `run_experiments` and `jobs`, and the `summary` recipe, now carries `diagnostics`: what the simulator said about the run, one entry per condition with how often it occurred, its first line as written, whether it came from the log or the console, and the simulator's own severity where it wrote one. A run that finished can still say `unknown_model_parameter`, which LTspice 26, LTspice XVII and ngspice all ignore and run on. A log line the server does not recognise is counted under `unclassified` instead of being dropped, and `diagnostics_coverage` says when a run's log was not read with its own simulator's and build's wording.
