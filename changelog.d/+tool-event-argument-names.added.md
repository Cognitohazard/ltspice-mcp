At `INFO`, each tool call's log record now names the argument fields the call set and the words of the server's own vocabulary it chose (an `inspect` kind, a recipe, a `jobs` action, an edit op), never a value. Resource reads and prompt gets each log one record naming the URI template or prompt, and Python API operations log the tool call's record with `door: "python_api"`. See "Server logging" in `docs/design/mcp_surface.md`.
