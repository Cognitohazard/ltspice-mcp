A model swap in `run_experiments` refused a model name that starts with a digit, such as `2N5486` or `1N4148`: a `REF@model` assignment failed each case at submission, and the `instances` form refused it at input. Both forms now accept a name of letters, digits and `_ . : -` that starts with a letter, digit or `_`. They refuse at input, naming the reason and the fix, a name the server must not write: one holding a space, a control character or a quote; one that reads whole as a number with at most a scale suffix (`2222`, `1k`, `1e3`), which a simulator can take for a value; and one holding a character no recording shows LTspice reading in a model name.
