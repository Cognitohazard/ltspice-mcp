# Native Sky130 statistical samples

The `pdk_native` variation runs the statistical models of a specific PDK
installation. The one supported profile is the generated Sky130A model set at
open_pdks revision `e6f9c8876da77220403014b116761b0b2d79aab4` and its
`sky130_fd_pr__nfet_01v8` devices. The PDK is installed separately, and when a
sandbox is set (`[security] allowed_paths`), the PDK must be inside it. Every
active protected file is checked against the profile's hashes; a similarly
named or edited installation does not qualify.

Author the bench with the PDK's ngspice library and its section `tt` for
nominal, `tt_mm` for mismatch or `mc` for process samples.

```spice
.lib "path/to/sky130A/libs.tech/ngspice/sky130.lib.spice" tt
```

Combined mode uses `mc` followed by root `.param mc_mm_switch=1`. Use one
`.op`, `.tran` or `.ac`, unit `m`/`mult`/`nf`, and positive resolved W/L. Omit
custom `.control`, `.step`, seed commands and other profile overrides, because
the server controls initialization. A device or analysis the profile does not
cover fails with a reason.

```json
{"kind": "pdk_native", "id": "samples", "profile": "sky130-e6f9c887-ngspice-v1",
 "mode": "combined", "runs": 20, "seed": 1947}
```

Add that entry to `run_experiments.variations` with `execution.simulator` set to
`ngspice`. Deterministic bench assignments can accompany it. Each sample runs
in a fresh process and sets its derived seed before the models load. For sample
7 alone, keep the inputs, ids, assignments and seed, then set
`runs: 1, sample_start: 7`. Parallel limits and job ids do not affect sample
identity. Exact reproducibility is tied to the recorded simulator build and
platform.

Inspect `native_statistics` in run receipts, or request full details with
`jobs(action="runs", job_id=..., run_fields=["native_statistics"])`. Each
missing fact has a reason, including on failed or skipped cases. Full
provenance records covered devices, original model hashes, effective seed,
simulator identity and exact prepared files. The PDK's internal random draws
are not reported; compute the statistics of your measurements from the runs.
